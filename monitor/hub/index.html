會不會被 Oracle 回收

Oracle 的規則：連續 7 天，CPU、記憶體、網路三項都低於 20%，閒置的免費主機可能被回收。只要任何一項高於 20% 就不會被判定閒置。

要看細節，點這裡

兩個工具各有擅長的事，這個總覽頁只是把最重要的整理成白話。

Uptime Kuma → 網站「過去」有沒有掛過、每次回應多久、憑證何時到期。通知（掛掉時寄信或訊息給你）也在這裡設定。 Netdata → VM 的詳細圖表：每個容器各用多少 CPU 與記憶體、網路流量、磁碟、Caddy 的請求量。要查「為什麼變慢」看這裡。
名詞白話對照
CPU 使用率
處理器忙碌的程度。一直接近 100% 才需要擔心。
記憶體使用率
程式實際占用的記憶體，不含系統拿來加速的快取，那部分需要時會自動讓出來。
第 95 百分位（p95）
把 7 天的數字由小排到大，取第 95% 的位置，意思是「幾乎整段時間的忙碌程度，忽略最忙的 5%」。Oracle 用它判斷是否閒置。
