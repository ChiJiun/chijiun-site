每 10 秒從 VM 本機檢查一次。「正常」代表對方有回應，而且回應內容是對的。卡片下方的「正常率」是你選的時間範圍內，被檢查到正常的比例。

4. 會不會被 Oracle 回收

Oracle 的規則：連續 7 天，CPU、記憶體、網路三項都低於 20%，閒置的免費主機可能被回收。只要任何一項高於 20% 就不會被判定閒置。

6. 要看更細的細節，點這裡

這個頁面是把最重要的整理成白話。更細的內容在下面兩個工具。

Uptime Kuma → 網站「過去」有沒有掛過、每次回應多久、憑證何時到期。通知（掛掉時傳訊息給你）也在這裡設定。 Netdata 看不懂？先看這裡 → 用白話教你打開 Netdata 之後該看哪 5 個地方、數字代表什麼、什麼情況才要擔心。 Netdata → VM 的詳細圖表：每個程式用多少資源、網路、磁碟、網站流量，每秒一筆。要查「為什麼變慢」看這裡。
名詞白話對照
CPU 使用率
處理器忙碌的程度。100% 代表一顆核心全滿；長時間接近滿載才需要擔心。
記憶體使用率
程式實際占用的記憶體，不含系統拿來加速的快取，那部分需要時會自動讓出來。
第 95 百分位（p95）
把 7 天的數字由小排到大，取第 95% 的位置，意思是「幾乎整段時間的忙碌程度，忽略最忙的 5%」。Oracle 用它判斷是否閒置。
就緒檢查（ready）
ncu-backend 的「檢索」和「PDF 對話」兩個子系統都準備好了，才算就緒。
回應時間
檢查程式向服務打招呼，到收到回覆花的時間。突然變很長，通常代表服務忙不過來。
站外看門狗
放在另一台獨立小主機上的檢查程式。它從「外面」連你的網站，所以即使這台 VM 整台停機也能發現並通知你。
正常率
在選定的時間範圍內，每次檢查都正常的比例。100% 代表一次都沒有失敗。
