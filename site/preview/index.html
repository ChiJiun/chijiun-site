三個範本，挑一個

每個都能實際操作，內容是同一份。建議用電腦開，鍵盤互動才玩得到。

A · KEYBOARD

互動鍵盤

  • 首頁是一把鍵盤，每個鍵帽是一項技能
  • 按實體鍵盤的字母鍵，鍵帽會跟著下壓
  • 鍵盤跟著滑鼠傾斜，背景點陣會被推開、起漣漪
打開 A → B · EDITOR

編輯器風格

  • 整個網站像一個程式編輯器，內容是一個個檔案
  • j / k 移動、數字鍵切換檔案、Enter 開連結
  • 按 : 輸入指令，例如 :theme、:help
打開 B → C · CANVAS

生成藝術背景

  • 背景是即時生成的線條，會繞著滑鼠流動
  • 卡片跟著滑鼠傾斜並打光，深淺色切換有擴散動畫
  • Ctrl K 開指令面板，用鍵盤跳到任何地方
